# DevOps Capstone Project

![Build Status](https://github.com/eidoriarch/devops-capstone-project/actions/workflows/ci-build.yaml/badge.svg)

This project develops a customer accounts microservice for an e-commerce application. The service provides REST API endpoints to create, read, update, delete, and list customer accounts containing basic customer information, including names and addresses.

The project uses Agile planning with GitHub and Zenhub to organize user stories, prioritize the product backlog, and plan development sprints.
